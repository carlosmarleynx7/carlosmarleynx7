<details>
<summary><strong>⚙️ Ativar a cobra (uma única vez)</strong></summary>
<br />
No repositório <code>carlosmarleynx7/carlosmarleynx7</code>, crie o arquivo <code>.github/workflows/snake.yml</code> com o conteúdo abaixo. Depois, em <strong>Actions → Generate snake → Run workflow</strong>, execute a primeira vez. A imagem aparecerá após a geração da branch <code>output</code>.

name: Generate snake
on:
  workflow_dispatch:
  schedule:
    - cron: '20 4 * * *'
  push:
    branches:
      - main
permissions:
  contents: write
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: carlosmarleynx7
          outputs: |
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark&color_snake=#00E5FF&color_dots=#0B1524,#16304C,#175A74,#00BBD4,#00E5FF
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

Se o GitHub bloquear a publicação, habilite <strong>Settings → Actions → General → Workflow permissions → Read and write permissions</strong> no repositório do perfil.

</details>
